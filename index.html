Analytics Lab

A small experimental website used to test Google Analytics 4 data collection.

About this project

Analytics Lab is a demonstration website created to learn how web analytics works. It is not a commercial website.

What are we testing?

This website will be used to test page-view collection and verify whether visits appear in the Google Analytics 4 Realtime report.

Explore the page

Refresh this page or return to it in another browser tab after analytics has been configured. Then check the Realtime report in Google Analytics.
